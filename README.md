# Lock Worlds

A lightweight Minecraft mod that lets you lock your worlds to prevent accidental deletion.

## Features

* Adds a lock option to the world selection screen
* Easily identify locked worlds
* Prevents accidental deletion of important saves
* Simple vanilla-style interface
* Client-side mod

Perfect for survival worlds, long-term builds, adventure maps, and worlds you never want to lose.

## Requirements

* Minecraft **26.3**
* **Fabric**

## Building

Clone the repository and run:

```bash
gradlew build
```
